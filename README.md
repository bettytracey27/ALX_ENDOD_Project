# ENDOD Water Tank Cleaning Website
This is my ALX portfolio project.  
I chose to work on my **own project** instead of the suggested ones, because this is my **family business** and I want to start solving problems from my home. Also i was trying before using php but when i start learning ALX i decided to do as a project using react. 

##  Project Idea
A responsive website for **ENDOD Water Tank Cleaning Services** in Addis Ababa.  
The site allows customers to learn about our services, view our work, and contact/ book us easily.  

##  Features
- Responsive public website with pages:
  - Home
  - About Us
  - Services
  - Our Work
  - Contact Us

 Tech Stack
Frontend Framework >	React + Vite
Styling >	Tailwind CSS
Icons >	Lucide Icons / Font Awesome
